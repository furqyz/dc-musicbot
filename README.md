### 📌 Proje Genel Bakışı

Sunucudaki kullanıcıların ses kanallarında müzik dinlemesi, çalma listeleri oluşturması ve kuyruk yönetimi yapabilmesi için geliştirilmiş sade, hızlı ve kullanıcı dostu bir müzik botudur.

---

### ⚡ Öne Çıkan Özellikler

- 🎶 **Kuyruk Yönetimi (Queue System):** Şarkı ekleme, çıkarma, sırayı görüntüleme ve karıştırma (shuffle).
- 🔊 **Temel Oynatma Kontrolleri:** Oynat (play), duraklat (pause), devam ettir (resume), geç (skip) ve durdur (stop).
- 🎚️ **Ses & Kalite:** Düşük gecikmeli ses akışı ve optimize edilmiş ses tamponlama (buffering).
- 💬 **Görsel Geri Bildirim:** Şarkı bilgisi, süre ve çalan parçayı gösteren temiz Discord embed arayüzleri.

---

### 🛠️ Kurulum & Çalıştırma

Projeyi yerel ortamında çalıştırmak için:

```bash
# 1. Repoyu klonla
git clone [https://github.com/furqyz/dc-musicbot.git](https://github.com/furqyz/dc-musicbot.git)

# 2. Proje dizinine gir
cd dc-musicbot

# 3. Bağımlılıkları yükle
npm install

# 4. Bot tokenini ve ayarları yapılandır
# 5. Botu başlat
node index.js
